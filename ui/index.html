FFXI Zone Editor v0.5

About

Direct DAT zone viewer and placement editor for FFXI zones.

  • Loads zone meshes, textures, placements, VFX, and sound emitters directly from DAT files.
  • Authentic FFXI lighting — weather environments, time of day, sun/moon direction, and fog ported from the client.
  • Collision (0x1C MZB) and server navmesh overlays for walkability review.
  • Move, rotate, scale, copy/paste, delete, and restore scene objects with full undo/redo.
  • Import custom GLB meshes into the scene.
  • Place and annotate markers (Spawn, NPC, Monster, Object, Trigger).
  • Save change-sets to workspace; publish directly to game DATs via the backend.
  • Export as JSON or individual xi CLI commands.
